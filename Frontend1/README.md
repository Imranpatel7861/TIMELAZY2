## Running Frontend Code

1. After clonning or downloading the branch and navigating inside the frontend folder.
2. Run the below commands.
   ```bash
   npm install
   ```
3. Run the project using below command
   ```bash
   npm run dev
   ```

4. After that create .env file inside frontend folder and enter the following line of code into it
   ```bash
   VITE_API_URL=http://127.0.0.1:5000/api
   ```
